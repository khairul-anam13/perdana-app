# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** React components via `@fortawesome/react-fontawesome` with SVG icon packages (no Kit, no CDN). Icons are bundled and tree-shaken, so they also work offline (precached by the service worker).
- **Version:** 7.3.1 (`@fortawesome/fontawesome-svg-core`, `free-solid-svg-icons`, `free-brands-svg-icons`); `@fortawesome/react-fontawesome` 3.5.0
- **License:** Free
- **Families:** classic (Solid), brands. Regular is not installed (not used). Duotone/Sharp/Light/Thin are Pro-only.

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

All icons are registered in ONE file, `src/components/ui/icons.tsx`. Components never import from `@fortawesome/*` directly.

- Add an icon: import `faXxx` from `@fortawesome/free-solid-svg-icons` (or `free-brands-svg-icons`) in `icons.tsx`, then export `export const IconXxx = make(faXxx)`.
- Use it: `import { IconXxx } from "@/components/ui/icons"` → `<IconXxx className="size-5" />`
- Module icons (nav + page header tile): `src/components/ui/module-icon.tsx`.
- Names: `fa-` + PascalCase of the icon name (`circle-user` → `faCircleUser`).

## Conventions

- Size with Tailwind `size-N` classes (default `size-6`). `make()` adds `shrink-0` so icons never shrink inside flex rows.
- Font Awesome CSS is imported in `src/app/globals.css` inside `layer(components)` so Tailwind size utilities win; `config.autoAddCss = false` is set in `icons.tsx`.
- Icons are decorative (`aria-hidden`); the meaning is always also in text or an `aria-label`.
- Colors come from the Perdana palette via Tailwind (`text-bata-600`, `text-padi-600`, …); modules are color+icon coded (`src/lib/modules.ts`).
- To move to Pro (e.g. Duotone), change only `icons.tsx` (and the package/registry setup); call sites stay the same.
